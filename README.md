A complete story in exactly six words, written by a small deterministic
Python program. Running `main.py` writes the story to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## The story

> He finally forgave her. Too late.

A lifetime of grudge in one word — *finally* — and the turn in the
last two: the forgiveness came, but it came too late. What she did,
whether she ever heard it, and what "too late" means are left for the
reader to fill in.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only. No network, no randomness — every run writes the
same bytes.
